# Фаза 1. Выбор концепции проекта

## Что здесь

| Файл | Что это |
|---|---|
| `phase-1.pdf` | отчёт c постановкой, оценками, обеими методиками с полными таблицами, анализом чувствительности, выводами |
| `topsis-and-mai-calculation.xlsx` | эксель с подсчётами топсис и маи. Есть возможность пересчитать, изменив значения |
| `phase-1.docx` | тот же отчёт, но исходник в ворде |

## Результат

Обе процедуры дали одного лидера **A1 - приложение для общих подписок и бытовых расходов соседей по квартире**.

## Как пересчитать

Правятся синие ячейки на листе «Оценки» в `topsis-and-mai-calculation.xlsx`. Тогда пересчитаются оба метода.

## Структура книги

- **Оценки** - исходные экспертные тройки (синее — редактируемое)
- **TOPSIS** - агрегация, нормализация, взвешивание, расстояния, CC. Столбец «Множитель k» -
  ручка для анализа чувствительности
- **МАИ** - дефаззификация PERT, групповые матрицы парных сравнений (AIJ), приоритеты, CR
- **Итог** - сводное сравнение двух методов
