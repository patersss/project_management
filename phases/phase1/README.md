# Фаза 1. Выбор концепции проекта

## Что здесь

| Файл | Что это |
|---|---|
| `Фаза1_отчёт.docx` | отчёт: постановка, экспертные оценки, обе методики с полными таблицами, анализ чувствительности, выводы |
| `Фаза1_расчёты.xlsx` | книга с живыми формулами: меняешь оценку — пересчитывается всё |
| `decision.py` | исходные данные + логика расчёта; генерирует оба файла выше |

## Результат

Обе процедуры дали одно упорядочение: **A1 ≻ A4 ≻ A3 ≻ A2**.
Выбрана **A1 — приложение для общих подписок и бытовых расходов соседей по квартире**
(CC = 0,5348 по нечёткому TOPSIS, глобальный приоритет 0,2723 по МАИ).

Единственная точка неустойчивости: при удвоении веса критерия C1 (зависимость от внешних
данных) лидером становится A4. Все матрицы парных сравнений согласованы, CR ≤ 0,012.

## Как пересчитать

```
pip install openpyxl python-docx
python decision.py
```

Правятся только константы `WEIGHTS` и `RATINGS` в начале `decision.py`. Скрипт прогоняет
самопроверку расчётного ядра, проверяет согласованность матриц (CR < 0,1) и перезаписывает
оба выходных файла.

Либо правятся синие ячейки на листе «Оценки» в `Фаза1_расчёты.xlsx` — тогда пересчитается
книга, но не отчёт.

## Структура книги

- **Оценки** — исходные экспертные тройки (синее — редактируемое)
- **TOPSIS** — агрегация, нормализация, взвешивание, расстояния, CC. Столбец «Множитель k» —
  ручка для анализа чувствительности
- **МАИ** — дефаззификация PERT, групповые матрицы парных сравнений (AIJ), приоритеты, CR
- **Итог** — сводное сравнение двух методов

Формулы книги сверены с расчётом `decision.py` — совпадение до 1e-9, ячеек с ошибками нет.
