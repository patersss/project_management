# Фаза 2. Распределение работы

В фазе 3 оцениваем приложение для общих подписок и бытовых расходов соседей
по квартире. За основу взяли концепцию A1 из [фазы 1](../phase1/README.md).
В MVP расходы вводятся вручную. Банковских интеграций и эквайринга в нём нет.

Отчёт с постановкой задачи и расчётами доступен в [PDF](phase-2.pdf) и
[Word](phase-2.docx).

## Исходные оценки

Для каждой задачи предусмотрены три независимые точечные оценки в человеко-часах.
Оценка включает подготовку, выполнение и проверку результата. Медиана тройки
задаёт трудоёмкость задачи для всех возможных исполнителей. Например, для COSMIC
из оценок 5, 4 и 4 часа получаем 4 часа. Сумма медиан по девяти задачам составляет
25 человеко-часов. Для T05 в нагрузку входит время ответственного на подготовку,
проведение обсуждения и фиксацию оценок.

Предпочтения оцениваются отдельно от времени по шкале от 1 (низкое) до 5 (высокое). 
В [estimates.csv](estimates.csv) сначала идут три оценки времени,
затем три оценки предпочтений. Порядок внутри обеих групп - Леонид, Дмитрий, Андрей.

## Распределение

Каждая задача получает одного ответственного. Нагрузка считается по медианным
трудозатратам и должна составлять от 7 до 10 часов на человека при среднем
ориентире 8,3 часа. В этих пределах максимизируем сумму предпочтений.
При равном балле выбираем меньшую разницу между максимальной и минимальной
нагрузкой. При равенстве обоих показателей берём первый вариант в порядке
строк CSV и участников.

| Ответственный | Задачи | Часы | Баллы |
|---|---|---:|---:|
| Челяпин Леонид | T03, T04, T07 | 9 | 15 |
| Засыпко Дмитрий | T05, T06, T08 | 8 | 14 |
| Сопельняк Андрей | T01, T02, T09 | 8 | 15 |
| **Итого** | **9 задач** | **25** | **44** |


## Как пересчитать

Из корня репозитория, используя Python 3.10 или новее:

```powershell
python phases/phase2/allocate.py
```

Скрипт проверяет все 19 683 назначения. Для другого набора оценок укажите
`--input` и путь к CSV. Границы нагрузки можно задать через
`--min-hours` и `--max-hours`. Формат CSV - UTF-8 с разделителем `;`.
