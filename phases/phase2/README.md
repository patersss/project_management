# Фаза 2. Распределение работы

В фазе 3 оцениваем приложение для общих подписок и бытовых расходов соседей
по квартире. За основу взяли концепцию A1 из [фазы 1](../phase1/README.md).
В MVP расходы вводятся вручную. Банковских интеграций и эквайринга в нём нет.

## Исходные оценки

Для каждой задачи предусмотрены три независимые точечные оценки в человеко-часах.
Оценка включает подготовку, выполнение и проверку результата. Медиана тройки
задаёт трудоёмкость задачи для всех возможных исполнителей. Например, для COSMIC FP
из оценок 5, 4 и 4 часа получаем 4 часа. Сумма медиан по девяти задачам составляет
25 человеко-часов. Для T05 в нагрузку входит время ответственного на подготовку,
проведение обсуждения и фиксацию оценок.

Предпочтения оцениваются отдельно от времени по шкале от 1 (низкое) до 5 (высокое).
Леонид ориентирован на расчётные методы, Дмитрий — на экспертную оценку и выводы,
Андрей — на постановку и описание сценариев. Числа заданы как рабочие допущения
для расчёта. В [estimates.csv](estimates.csv) сначала идут три оценки времени,
затем три оценки предпочтений. Порядок внутри обеих групп — Леонид, Дмитрий, Андрей.
