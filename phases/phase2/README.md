# Фаза 2. Распределение работы

В фазе 3 оцениваем приложение для общих подписок и бытовых расходов соседей
по квартире. За основу взяли концепцию A1 из [фазы 1](../phase1/README.md).
В MVP расходы вводятся вручную. Банковских интеграций и эквайринга в нём нет.

## Задачи фазы 3

| Код | Задача | Результат | Предшественники |
|---|---|---|---|
| T01 | Определить границы MVP, акторов и список из 10–15 Use Cases | Реестр сценариев и список акторов | — |
| T02 | Описать основные и альтернативные сценарии | Описания сценариев с основными и альтернативными потоками | T01 |
| T03 | Рассчитать COSMIC FP | Таблица перемещений данных и итоговая функциональная оценка | T02 |
| T04 | Рассчитать UCP и оценить трудозатраты по UCP | Расчёт UCP и перевод в человеко-часы | T02 |
| T05 | Организовать коллективную оценку Use Cases и согласовать результаты | Согласованные трудозатраты по каждому Use Case | T02 |
| T06 | Агрегировать коллективные оценки до уровня проекта | Суммарная экспертная оценка трудозатрат | T05 |
| T07 | Сопоставить оценки трёх методов | Сводная таблица и пояснение различий | T03, T04, T06 |
| T08 | Обосновать размер команды, срок и возможные сокращения MVP | Рекомендации по составу команды, сроку и объёму MVP | T07 |
| T09 | Собрать и проверить отчёт фазы 3 | Отчёт с расчётами и выводами | T08 |

После описания сценариев COSMIC, UCP и коллективную оценку можно выполнять
параллельно. В T05 ответственный готовит материалы, организует обсуждение
и фиксирует согласованные оценки. В обсуждении участвуют все трое.
